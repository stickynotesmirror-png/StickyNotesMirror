# Sticky Notes Mirror

Sticky Notes Mirror is a free Windows companion for Microsoft Sticky Notes.

It adds:
- remote database synchronization
- workstation-specific note routing
- deleted note recovery
- Firebird and MariaDB / MySQL support
- additional management and formatting tools
